# Security and responsible use

This package contains prompts and engineering instructions only; it does not perform scans, enforce authorization, or access external services on its own.

**Never commit:** provider keys, credentials, `.env*` files, internal customer records, private log exports, unredacted error reports, JWTs, access tokens, database connection strings or operationally sensitive runbooks. Review repository history and branches before publishing.

Report issues in this skills package through a GitHub issue without including sensitive examples; use private reporting mechanisms for suspected credential disclosure.

Only run destructive or production-facing operations after explicit approval and with scoped permissions. Treat any project-specific examples as design hints, not verified production vulnerabilities.
