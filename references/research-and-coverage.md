# Research and coverage audit — 2026-10-30

The DevFlowForge v0.5.0 expansion reviewed public GitHub repositories for **coverage and architecture ideas**, not source code to copy:

- Anthropic Skills — https://github.com/anthropics/skills — visual design, webapp testing, skill format and workflows.
- Vercel Agent Skills — https://github.com/vercel-labs/agent-skills — web design audits, React/Next.js and React Native performance.
- Superpowers — https://github.com/obra/superpowers — test-first development, planning, verification and review.
- UI UX Pro Max — https://github.com/nextlevelbuilder/ui-ux-pro-max-skill — design systems, multi-platform UI and design research.
- Web Quality Skills — https://github.com/addyosmani/web-quality-skills — field/lab metrics, accessibility and SEO.
- GitHub Awesome Copilot — https://github.com/github/awesome-copilot — catalogue of specialised skills and contributor workflows.
- Agent Skills — https://github.com/agentskills/agentskills — portable SKILL.md structure and progressive disclosure.

We compared those themes against 30 existing DevFlowForge skills. We selected 47 narrow additions spanning product, visual design, frontend/mobile, API/data, infrastructure, security/quality and agent skills. Existing skill names are preserved. New text was independently authored and carries DevFlowForge's own workflows. GitHub stars, catalog size and popularity are *not* evidence of the effectiveness of any skill.

## Coverage after expansion
- Product research, user journeys, specifications, UX copy and experiments.
- Brand identity, UI/UX, design systems, wireframes, Figma handoff, visual critique, data dashboards, accessible interaction, responsive/mobile patterns and design-to-code.
- Frontend architecture, async state, framework architecture, browser tests and web vitals.
- Mobile, desktop and CLI experiences.
- APIs, auth, realtime, queries, pipelines, distributed systems, caching, privacy and disaster recovery.
- Load testing, contract compatibility, CI/CD, IaC, containers, cloud cost and progressive delivery.
- AI tool safety, retrieval quality, skill evaluation and monorepo maintenance.

## Residual limitations
This is an *instruction toolkit*, not an exhaustive specialist knowledge base, rendering engine, design application or automated code executor. The correct skill for any task still depends on source evidence and available tools. Future skills should be added based on measured gaps and sample tasks, not to maximize a skill count.
