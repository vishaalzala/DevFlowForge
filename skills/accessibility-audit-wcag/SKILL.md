# Accessibility audit and remediation

**When activated:** Apply this only if the actual task matches the description. First inspect available evidence and select relevant references; do not infer project details from the skill name.

## Workflow
1. Define scope and applicable standard; inspect semantic structure, headings, landmarks, labels and name/role/value.
2. Test keyboard-only flow, focus visibility/order, dialogs, error identification, touch alternatives and screen-reader announcements.
3. Evaluate contrast, text resizing, motion settings, target size and non-color indicators on real screens.
4. Combine automated checks with manual assistive-technology and usability testing; automation cannot certify compliance.
5. Rank issues by user impact and provide reproducible steps, locations, remediation and retest evidence.

## Deliverable
Accessibility findings with reproduction, severity and verification status.

## Quality gate
Report what was **observed**, what is **proposed**, which checks **passed/failed/were not run**, and any remaining risks. Use tools only when available and authorised. For destructive, financial, production or customer-data changes, require explicit approval. Never claim a test, screenshot, design file, deployment or tool action exists without evidence.
