# Visual and UX design critique

**When activated:** Apply this only if the actual task matches the description. First inspect available evidence and select relevant references; do not infer project details from the skill name.

## Workflow
1. Ground the audit in actual screens and user tasks; separate taste preferences from usability or accessibility failures.
2. Check hierarchy, alignment, whitespace, typography, consistency, density, content truncation, mobile balance and contrast.
3. Identify state coverage and interaction affordances, including loading, empty, error and keyboard focus.
4. Rank improvements by user impact, evidence, change effort and risk to existing behavior.
5. Provide specific design recommendations and ways to compare before/after; do not promise aesthetic superiority.

## Deliverable
Prioritized critique with concrete observations and acceptance checks.

## Quality gate
Report what was **observed**, what is **proposed**, which checks **passed/failed/were not run**, and any remaining risks. Use tools only when available and authorised. For destructive, financial, production or customer-data changes, require explicit approval. Never claim a test, screenshot, design file, deployment or tool action exists without evidence.
