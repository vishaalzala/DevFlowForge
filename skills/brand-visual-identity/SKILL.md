# Brand and visual identity systems

**When activated:** Apply this only if the actual task matches the description. First inspect available evidence and select relevant references; do not infer project details from the skill name.

## Workflow
1. Understand positioning, audience, desired perception, tone and existing brand materials before proposing visuals.
2. Define typography, palette, imagery style, icons, spacing and brand application rules; verify rights to assets.
3. Create examples for light/dark backgrounds, different screen densities and accessibility needs.
4. Prepare usage constraints for logos, marks, contrast, minimum sizes, clear space and export formats.
5. Review distinctiveness and consistency, and avoid claiming trademark clearance without a formal search.

## Deliverable
Mini brand guide, asset checklist, variants and usage examples.

## Quality gate
Report what was **observed**, what is **proposed**, which checks **passed/failed/were not run**, and any remaining risks. Use tools only when available and authorised. For destructive, financial, production or customer-data changes, require explicit approval. Never claim a test, screenshot, design file, deployment or tool action exists without evidence.
