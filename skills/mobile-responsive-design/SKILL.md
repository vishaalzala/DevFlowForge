# Mobile and responsive UX design

**When activated:** Apply this only if the actual task matches the description. First inspect available evidence and select relevant references; do not infer project details from the skill name.

## Workflow
1. Identify real device ranges, touch targets, safe areas, keyboard behavior and content priority at each breakpoint.
2. Select adaptive patterns based on task complexity rather than simply shrinking desktop layouts.
3. Design navigation, forms, overlays, tables and charts for one-handed or touch use where relevant.
4. Check text scaling, localization, contrast, zoom, screen readers and reduced-motion preferences.
5. Validate on representative narrow/wide viewports and real devices where available; record unresolved platform issues.

## Deliverable
Responsive behavior specification and device QA matrix.

## Quality gate
Report what was **observed**, what is **proposed**, which checks **passed/failed/were not run**, and any remaining risks. Use tools only when available and authorised. For destructive, financial, production or customer-data changes, require explicit approval. Never claim a test, screenshot, design file, deployment or tool action exists without evidence.
