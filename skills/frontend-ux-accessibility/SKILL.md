# Professional, functional interface changes

1. Understand page purpose, target users, existing pages and navigation. Inspect current components/screens and design system; avoid duplicating already-implemented features or changing unrelated modules.
2. Use clear spacing, readable default text (including menu and body), accessible contrast, keyboard navigation, visible focus, semantic HTML, touch-sized controls and responsive layouts.
3. Preserve form state, validation, tax/currency labels, loading/error/empty states, autosave, print/PDF outputs and locale-specific formats where applicable.
4. Build reusable components compatible with current stack. Avoid adding unnecessary dependencies, excessive animation or layout shifts. Enforce server authorization independently of UI visibility.
5. For marketing pages, check copy accuracy, heading hierarchy, alt text, canonical URLs, metadata, indexability, sitemap and performance. Do not assert SEO rankings.
6. Test desktop/mobile, keyboard, slow network, empty and long content, error cases and critical user routes. Summarize before/after behavior and any outstanding visual review.
