# Seo Content Automation

**Goal:** Publish useful, accurate, discoverable content without harming site performance.

Read `../../references/quality-gates.md` and apply the relevant project context in `../../references/projects.md`; both are hints rather than verified code state. If available, use authorized tools and inspect evidence before modifying anything.

## Procedure
1. Inspect canonical URLs, robots, sitemap indexes, metadata, structured data and content uniqueness in the deployed site.
2. Build topic clusters with intent-aligned pages and relevant internal links; avoid deceptive competitor-keyword stuffing and duplicate location pages.
3. For generated articles require factual review, clear authorship, original value, canonicalization and scheduled drafts rather than unchecked mass publishing.
4. Generate sitemap updates from publish state; ensure deleted or unpublished pages are excluded from internal links and indexing hints.
5. Monitor indexing issues, broken links and CWV changes without claiming ranking improvements before evidence exists.

## Verification checklist
- Sitemap links return intended status.
- Canonical and structured data validated.
- Publishing safeguards tested.

**Output:** Findings with evidence, proposed or actual change, exact testing status (Pass/Fail/Not run), risk and rollback, and links only to resources actually created. No unsupported claims about production access or running agents.
